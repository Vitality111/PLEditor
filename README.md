# PB — конструктор плейблів

PB робить варіації плейбл-реклами **Fiction Me** і **Cleaner** без коду. Береш готовий креатив,
міняєш текст, картинки, кнопку, музику й посилання та експортуєш один HTML, готовий для рекламних мереж
(AppLovin, Meta, MRAID). Портрет і ландшафт, екрани від 320×480 до великих телефонів і планшетів.

## Запуск

Потрібен **Node.js 18+** (https://nodejs.org). Більше нічого встановлювати не треба.

```
npm start
```

Потім відкрий у браузері **http://127.0.0.1:4173**. Інший порт: `PORT=8080 npm start`.

На сервер (хостинг): папка як є, команда `node server.mjs` (змінні `HOST`, `PORT`; перевірка `/healthz`).
Є `Dockerfile`. Сервер лише віддає сторінки — нічого не зберігає.

**GitHub Pages** теж підходить: PB — статичний сайт. Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
Адреса буде `https://<акаунт>.github.io/<репо>/` (корінь сам перекидає в `app/`). Для приватного репо
Pages працює лише на платних планах GitHub.

## Як працювати

1. **Старт** — обери продукт (Fiction Me / Cleaner), далі шаблон або «Свій плейбл» (HTML чи ZIP).
2. **Редактор** — ліворуч елементи креативу й файли, у центрі preview, праворуч налаштування вибраного елемента.
3. **Експорт HTML** — готовий файл з усіма картинками, шрифтами й музикою всередині (до 5 МБ).

## Що можна

- **Текст** — змінити, виділити слова й зробити **жирним**, *курсивом*, підкресленим або іншим шрифтом;
  шрифт для всього тексту, свій шрифт (.ttf/.otf/.woff).
- **Картинки** — замінити; окрема картинка для ландшафту; фон креативу теж замінюється.
- **Рухати й розтягувати** — як у Figma: тягни елемент і квадратики по краях.
- **Нові елементи** (текст, картинка) — прив’язуються до сусіднього елемента креативу й тримаються біля нього
  на всіх розмірах екрана; можна обрати, до чого прив’язати.
- **Показувати у портреті / у ландшафті** — кожну орієнтацію окремо.
- **Кнопка CTA** — картинку можна замінити кнопкою з кодом (текст, колір, заокруглення).
- **Музика** — вимкнути, замінити своїм файлом, повернути оригінал.
- **Посилання на магазин** (вкладка «Експорт») — порожні поля: посилання креативу; одне — для всіх телефонів;
  два — iPhone у App Store, Android у Google Play.
- **Варіації** 1 / 2 / 3 одного креативу; експорт усіх одним ZIP з правильними назвами файлів.
- **Тест** — креатив працює як у рекламі (його скрипти, анімації, тап по CTA).
- **Скріншот** — PNG екрана креативу (2×), заодно копіюється в буфер, щоб вставити в борд.
- **Розміри екрана** й масштаб preview, лінійки, напрямні.

## Збереження

У браузері зберігається **лише останній креатив** (після перезавантаження він відкривається сам).
Новий креатив замінює збережений. На сервер нічого не йде. Щоб продовжити роботу пізніше чи на іншому
комп’ютері — відкрий експортований HTML через «Свій плейбл»: усі правки на місці.

## Для розробника

- Код — `app/` (ES-модулі без збірки), сервер — `server.mjs`, вигляд — за ТЗ `DESIGN.md`.
- Тести: `npm install`, далі `npm test` (швидкі) і `npm run test:all` (усі браузерні, з Playwright).
  Браузер: `CHROME_PATH`, інакше встановлений Chrome. Тест імпорту бере `cleaner/00159/1`
  з `PLAYABLE_ADS_ROOT` (за замовчуванням `../PlayableAds`).
- Історія змін — `CHANGELOG.md`. Сторонні бібліотеки та ліцензії — `app/vendor/NOTICE.md`.
